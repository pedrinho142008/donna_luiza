# Fotos do site Donna Luiza

O site está preparado para usar suas fotos originais, com estes nomes exatos. Coloque os arquivos em `public/assets/`:

- `logo-donna-luiza.png` — logo oficial (se tiver a versão PNG, pode substituir o símbolo provisório no cabeçalho/rodapé)
- `praia-zumbi.jpg` — imagem panorâmica da praia para a abertura
- `ambiente-praia.jpg` — ambiente do restaurante
- `pizza-doce-chocolate-banana.jpg`
- `file-peixe-molho-tomate-gratinado.jpg`
- `sobremesa-creme-tropical.jpg`
- `camarao-empanado-arroz-colorido.jpg`
- `cuscuz-polvo-queijo-coalho.jpg`
- `cuscuz-carne-de-sol.jpg`
- `arroz-cremoso-camarao-gratinado.jpg`
- `gratinado-frutos-do-mar.jpg`

As imagens de pratos são referenciadas pelos nomes sugeridos e têm uma fotografia de demonstração como alternativa. Quando você colocar uma imagem local com o nome correspondente, o site prioriza o arquivo local automaticamente. A imagem oficial da marca não veio anexada a esta sessão; o SVG atual é apenas um símbolo provisório inspirado na descrição da logo.
